# พื้นที่เป้าหมาย

แผนงาน มี.ค. 2568 – มี.ค. 2570 รวม 12 จังหวัด

| จังหวัด | ประเด็น/แกนเรื่อง | สถานะ |
|---|---|---|
| ศรีสะเกษ | เมืองบูรณาการลดปัจจัยเสี่ยง | **มีแผน ยังไม่เริ่ม** |
| อ่างทอง | (บวชสร้างสุข) | ดำเนินการแล้ว |
| ตาก | กระทงสายสุขใจ | ดำเนินการ |
| สุรินทร์ | งานช้างสุรินทร์ | ดำเนินการแล้ว |
| น่าน | เด็กน่านโตที่นี่ได้ไหม | ดำเนินการ |
| ร้อยเอ็ด | เยาวชนสุขเกินร้อย | ดำเนินการ |
| แม่ฮ่องสอน | วิถีวัฒนธรรม | ดำเนินการ |
| นครศรีธรรมราช | บุญสารทเดือนสิบ | ดำเนินการแล้ว |
| สุโขทัย | ลอยกระทงเผาเทียนเล่นไฟ | ดำเนินการ |
| ขอนแก่น | สงกรานต์ถนนข้าวเหนียว | ดำเนินการแล้ว |
| เชียงราย | เยาวชน | **มีแผน ยังไม่เริ่ม** |
| พะเยา | แม่ใจ อำเภอลดปัจจัยเสี่ยง | **มีแผน ยังไม่เริ่ม** |

## งานระดับภาค (ไม่ผูกกับจังหวัดเดียว)

| งาน | พื้นที่ | สถานะ |
|---|---|---|
| งานศพปลอดเหล้า | ภาคอีสาน, ภาคเหนือ | กำลังดำเนินการ |

รายละเอียดประเด็นงานศพอยู่ในไฟล์ `06-issue-funeral.md`

## วิธีตอบเรื่องพื้นที่

- **เชียงราย , ศรีสะเกษ และ พะเยา** ยังอยู่ขั้นวางแผน ยังไม่เริ่มดำเนินการ ถ้ามีคนถามถึงสามจังหวัดนี้
  ให้บอกตามจริงว่ามีแผนอยู่แต่ยังไม่เริ่ม อย่าตอบเหมือนงานเดินแล้ว
- รายละเอียดเฉพาะของแต่ละโปรเจค (ตัวเลข ผลลัพธ์ กำหนดการ) ให้ยึดเอกสารจักรวาลล่าสุดของทีม
  ถ้าไม่มีในไฟล์นี้ ให้บอกว่าต้องตรวจสอบกับทีมเพิ่ม ห้ามเดา

> เวลาเพิ่ม/ลบจังหวัด อย่าลืมแก้ตัวเลขรวมในบรรทัดบนสุดให้ตรงด้วย
